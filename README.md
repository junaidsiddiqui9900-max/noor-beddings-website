# Noor Beddings — College Project Website

A responsive e-commerce style front-end website for Noor Beddings.

## Features
- Responsive homepage and navigation
- Pure Cotton and Mix Cotton collections
- Product catalogue with design numbers and prices
- Add-to-cart functionality
- Cart drawer with quantity controls
- Checkout form
- Cash on Delivery option
- UPI QR payment flow
- WhatsApp order confirmation
- Mobile-friendly layout

## Run locally
1. Open `index.html` directly in a browser, or
2. In VS Code, install the Live Server extension and choose **Open with Live Server**.

## Put it online with HTTPS
You can deploy this static website using GitHub Pages, Netlify, or Vercel. These platforms provide HTTPS automatically for the deployed site.

## Important for a real production store
This project is currently a front-end/demo implementation. Customer orders are sent through WhatsApp and there is no secure server/database, inventory system, authentication, or payment gateway verification. For a production e-commerce system, add a backend, database, server-side order validation, and a proper payment gateway.
